# كورد (CORD)

**بروتوكول مفتوح من Hantera · أنشأه KentPH**

كورد هو مسودة بروتوكول مفتوح ومحايد تجاه مزوّدي الخدمات، تهدف إلى إنشاء أدلة تشفيرية حول أحداث الذكاء الاصطناعي والتحقق منها بشكل مستقل.

## ماذا يفعل الإصدار الأساسي 0.1؟

يستخدم كورد ملفين بصيغة JSON:

- `bundle.json`: وصف موجز لحدث متعلق بالذكاء الاصطناعي.
- `receipt.json`: يحتوي على بصمات تشفيرية للبيانات الموجودة في الحزمة وللبايتات الأصلية للملف.

يتحقق المدقّق من بنية الحزمة ومن تطابق بصمات SHA-256. ويمكن إجراء التحقق دون اتصال بالإنترنت.

تعني نتيجة `PASS` أن الحزمة المقدّمة تطابق قواعد الإصدار المدعوم وأن البصمات تتطابق مع الإيصال المقدّم. لكنها **لا تثبت** هوية منشئ الملفات، أو أن نموذج الذكاء الاصطناعي المذكور هو الذي أنشأ المخرجات، أو أن الطابع الزمني موثوق. وإذا استطاع مهاجم استبدال الحزمة والإيصال معاً، فيمكنه إنشاء زوج جديد متطابق داخلياً.

> **الحالة: مسودة تجريبية (0.1).** لا تستخدم كورد حالياً كشهادة أمان للإنتاج. لا تزال هناك حاجة إلى مراجعة مستقلة للبروتوكول والتنفيذ.

## البدء السريع

يتطلب التحقق الأساسي Python 3.10 أو إصداراً أحدث، ولا يحتاج إلى حزم خارجية.

```bash
python verifier/verify.py create bundle.json receipt.json --created-at 2026-03-06T12:00:05Z
python verifier/verify.py verify bundle.json receipt.json
python -m unittest discover -s tests -v
```

يعرض المدقّق النتيجة بصيغة JSON. ويعيد رمز خروج `0` عند النجاح و`1` عند وجود مدخلات غير صالحة أو فشل في التحقق.

## مبادئ التصميم

- بروتوكول مفتوح ومحايد تجاه مزوّدي الخدمات.
- التحقق دون اتصال بالإنترنت، ومن دون حساب كورد أو خادم كورد.
- مخططات بيانات صارمة وبيانات اختبار حتمية.
- إضافات الثقة الاختيارية لا تغيّر قواعد البصمات في النواة.
- لا تدّعي البصمات وحدها إثبات الهوية أو الوقت الموثوق أو صحة المحتوى أو الامتثال.

## التكامل مع Python

تتوفر مكتبة مساعدة أولية في `sdk/python/cord_sdk.py`، مع مثال في `examples/python_quickstart.py`.

## التكامل مع TypeScript (تجريبي)

تتوفر مكتبة SDK تجريبية لـ Node.js 20 أو أحدث في `sdk/typescript`. يجب على التطبيق الذي يقرأ ملفات JSON استخدام محلّل يرفض مفاتيح JSON المكررة؛ لأن `JSON.parse` المدمجة في JavaScript لا ترفضها.

```bash
cd sdk/typescript
npm install
npm test
```

## إضافات تجريبية

- توقيع الإيصال باستخدام Ed25519.
- سلسلة أحداث تربط الإيصالات ببصماتها.

تتطلب هذه الإضافات مفاتيح أو نقاط تحقق موثوقة يتم الحصول عليها من مصدر خارجي. ولا تحوّل كورد إلى شهادة أمان للإنتاج.
