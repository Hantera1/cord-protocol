# Security Policy

## Reporting Security Issues

If you discover a security vulnerability in the Cord protocol, reference implementation, or verification logic, please report it responsibly.

Security issues should **not** be disclosed publicly before they are reviewed.

Please open a private issue or contact the repository maintainer.

---

## Scope

Security concerns may include:

- vulnerabilities in the Cord verification logic
- weaknesses in bundle or receipt validation
- cryptographic misuse
- implementation flaws that could allow verification bypass

---

## Responsible Disclosure

We ask researchers to follow responsible disclosure practices:

1. report the issue privately
2. allow time for investigation
3. coordinate public disclosure if necessary

---

## Security Goals

Cord aims to provide:

- deterministic verification
- minimal attack surface
- reproducible validation
- transparent verification rules

Security feedback is welcome and helps improve the protocol.
