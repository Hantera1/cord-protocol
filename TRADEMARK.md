# Cord Name and Trademark Policy

The name "Cord" refers to the Cord protocol specification and its reference implementations maintained in this repository.

This project aims to keep the Cord protocol openly implementable while protecting the integrity of the name "Cord" so that users are not misled about official implementations.

## 1. Open Implementation

Anyone may implement the Cord protocol specification without requesting permission.

Implementations may state that they:

- implement the Cord protocol
- are compatible with the Cord specification
- support the Cord verification format

Examples of acceptable statements:

This system implements the Cord protocol.

Compatible with the Cord specification v0.1.

## 2. Use of the Name "Cord"

You may use the name Cord when referring to:

- the Cord protocol
- compatibility with the Cord specification
- educational, research, or documentation material describing Cord

This includes documentation, blog posts, academic work, and compatible implementations.

## 3. Restricted Uses

You may not use the name Cord in ways that suggest:

- official endorsement by the Cord project
- ownership of the Cord protocol
- that your product is the official Cord implementation

Examples of restricted usage include names such as:

Official Cord Platform  
Cord Foundation  
Cord AI  
Cord Protocol Official

unless explicitly authorized by the maintainers of the Cord project.

## 4. Official Cord Projects

The following may be considered official Cord resources:

- the Cord specification repository
- the Cord reference verifier
- any repositories explicitly listed by the maintainers of this project

Only these may represent themselves as official Cord implementations.

## 5. Logos and Branding

If a Cord logo or branding assets are introduced in the future, their use may be restricted to official Cord projects unless explicit permission is granted.

## 6. Governance

The Cord protocol may evolve through future versions of the specification.

Future governance may include:

- a formal specification process
- compatibility guidelines
- reference implementations
- certification of compatible systems

## 7. Project Goal

The goal of the Cord protocol is to enable:

- verifiable AI events
- deterministic auditability
- cryptographic integrity of AI outputs

while remaining openly implementable and transparent.

## 8. Disclaimer

This policy is intended to clarify acceptable use of the name Cord within the context of this open-source project.

Nothing in this document grants trademark rights beyond those allowed by applicable law.
