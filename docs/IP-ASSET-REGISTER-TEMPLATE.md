## Required evidence
- original files and version history;
- contributor identity and engagement terms;
- signed assignment or license;
- third-party license inventory and notices;
- invoices and contractor agreements;
- board approval and valuation/tax note where rights move between related parties.

A GitHub repository owner, README attribution or company name alone is not proof that every contributor's copyright has been assigned.
